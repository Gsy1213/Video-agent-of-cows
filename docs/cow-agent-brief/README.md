如何使用这份 AI 编码指引
本目录交付的是完整软件的开发规格和提示词，不是已经实现的软件。模型训练、数据采集/标注、真实视觉推理与跟踪由另一位同学完成。
使用步骤
给编码 AI 一个新的空项目目录，避免在无关项目中混合开发。
将本目录的全部文件一并提供给它，或让它读取本目录的绝对路径。
复制 00-交给AI的启动提示词.md 的正文，明确目标项目目录后发送。
AI 按 04-编码执行与验收关卡.md 的 M0～M6 阶段实现，每阶段通过验收再继续，并提供实际运行和测试证据。
把第 6 节、Schema 和样例发给视觉同学确认交接协议；当前这是一份建议协议，尚未与实际模型联调。

verify_brief.py
指引包结构、样例数值和引用关系自检，不替代软件测试
样例中的视频指纹是明确的占位值。它可通过 JSON 结构验证，但不能直接作为真实上传视频的结果导入。实现 seed 脚本时应生成演示媒体、替换真实指纹与视频编号；导入任务的服务器编号按照指引进行重绑定。
“软件离线验收通过”和“真实模型/大模型接入验证通过”必须分开记录。没有模型权重、密钥或专业资料时，可以完成前者，不能冒充完成后者。
提示词不能保证零缺陷。本文通过明确接口、固定数值样例、失败分支和可执行测试要求，减少实现歧义。拿到成品后，应以运行结果与验收报告判断完成程度。
